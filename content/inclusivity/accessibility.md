We use the Reka UI library to support keyboard navigation and accessible behavior in our UI components.
The following components help you navigate and interact with the wiki:

- Splitter: View Binder and View Model, providing adjustable layout
- Accordion: Sidebar Menu to Expand/Collapse a parent document
- Collapsible: Collapsible paragraph
- Dialog: Search Bar (also Manages focus and screen reader announcements)
- Tabs: View Binder and View Model right panel.
- Tooltip: Inline annotation
- Tree: View Binder, to navigate between models and directories

Try each component below to learn what it does and practice using it with a keyboard.
